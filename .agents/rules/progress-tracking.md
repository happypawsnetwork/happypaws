# Progress Tracking Rules

Whenever you implement a feature, fix a bug, or complete a task that corresponds to our documented requirements, you must update the progress trackers in our documentation.

## Guidelines

1. **Update User Stories**: If you fulfill a user story, open the relevant file in `docs/requirements/user-stories/` and update the completion status from `❌` to `✅` in the table.
2. **Update Features**: If you implement a documented sub-feature or feature, open the relevant file in `docs/requirements/features/` and change the corresponding item from `❌` to `✅`.
3. **Use Emojis**: Always use emojis (`✅` for implemented/completed and `❌` for not implemented/incomplete) to track status. Do not use standard Markdown checkboxes (`[ ]` and `[x]`).
4. **Be Proactive**: Do not wait for the user to explicitly ask you to mark a feature as done. If you have confidently completed the implementation (and it's completely implemented in the app), update the trackers automatically as part of your task execution.
