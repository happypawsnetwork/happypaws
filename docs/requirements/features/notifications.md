# Email & Notifications

Communication outside of the app ensures users remain informed about security events and case updates.

## Custom Email Templates
- ✅ All emails sent via the Resend API use custom HTML templates.
- ✅ **Styling**: Templates adhere to a consistent, professional formatting standard across the platform.

## Key Notification Triggers
- ✅ OTP generation for registration, web login, and password resets.
- ❌ Geo-targeted push alerts via FCM for new rescue cases.
- ✅ In-app unread message alerts.
- ❌ Status changes on sponsored, fostered, or assigned transport cases.
