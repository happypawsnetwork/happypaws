# Administrator functionalities

| User story | Functionality | Description | Completed |
| --- | --- | --- | --- |
| As an administrator, I want to log in to the web administration panel so I can access verification and case data. | Login and authentication | Signs in to the web administration panel with elevated, role-based access enforced through JWT. | ✅ |
| As an administrator, I want to review identity verification documents so I can approve or reject accounts before they gain full privileges. | Identity verification review | Inspects a submitted identity document, clinic registration, or license for any role and approves or rejects it before the account gains full privileges. | ❌ |
| As an administrator, I want to view a live case map so I can coordinate several simultaneous rescues. | Live case map and rescue coordination | Views all active rescue cases plotted on a map, monitors their AI-assigned urgency and current status, and follows each one through to resolution. | ✅ |
| As an administrator, I want to review AI triage and override Gemini's urgency classification when necessary so I can prevent wrong decisions. | AI triage oversight | Reviews and, where necessary, overrides Gemini’s urgency classification for a reported case, alongside the same override available to a veterinarian. | ✅ |
| As an administrator, I want to moderate content so I can remove listings or messages that violate platform rules or raise fraud concerns. | Content moderation | Reviews and removes adoption listings, messages, or profiles that violate platform rules or raise a fraud concern. | ❌ |
| As an administrator, I want to manage user accounts so I can activate, suspend, or remove them if there is evidence of misuse. | User account management | Activates, suspends, or removes an account, including one already verified, if evidence of misuse appears. | ✅ |
| As an administrator, I want to handle reputation and disputes so I can adjust points or badges manually when required. | Reputation and dispute handling | Adjusts reputation points or trust badges manually where a dispute between users requires it. | ✅ |
| As an administrator, I want to view an admin dashboard so I can see a summary of pending verifications, open cases, and overall platform activity. | Admin dashboard and reporting | Sees a summary of pending verifications, open cases, and overall platform activity from a single web dashboard. | ✅ |
| As an administrator, I want to see all rescue cases with an approved applicant in the Rescues tab so I can monitor active fostering assignments. | Rescue case monitoring | Views all active rescues with an approved applicant in the rescues tab. | ✅ |
| As an administrator, I want to override a rescue case back to Active so the original poster can select a different applicant if needed. | Rescue case override | Reverts a fostered rescue case back to active status to allow new applicant selection. | ✅ |
| As an administrator, I want to view all transport tasks and their statuses in the Transports tab so I can monitor animal movement across cases. | Transport task monitoring | Views all transport tasks and their statuses across the platform. | ✅ |
| As an administrator, I want to review pending sponsorship requests in the Sponsorships tab and approve or reject them with an optional note so only legitimate requests appear in the community feed. | Sponsorship review | Approves or rejects pending sponsorship requests before they appear in the community feed. | ✅ |
| As an administrator, I want to download sponsorship proof documents so I can verify a request is legitimate before approving it. | Proof document verification | Downloads and reviews private proof documents attached to a sponsorship request. | ✅ |
| As an administrator, I want to moderate community posts by soft-deleting inappropriate content from the Community tab. | Community moderation | Soft-deletes inappropriate community posts from the dashboard. | ✅ |
