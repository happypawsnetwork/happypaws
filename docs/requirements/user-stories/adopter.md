# Adopter and owner functionalities

| User story | Functionality | Description | Completed |
| --- | --- | --- | --- |
| As a user, I want to register for an account so I can join the platform. | Registration | Creates an account. Every user is signed up as an adopter initially. | ✅ |
| As a user, I want to assign myself roles in my dashboard so I can access features like fostering or transporting. | Role assignment | Assigns additional roles from the application dashboard later. Roles requiring KYC verification require submitting KYC documents. | ✅ |
| As a user, I want to sign in securely so I can access my dashboard and data. | Login and authentication | Signs in securely, with role-based access enforced through JWT so the session only exposes adopter-facing screens and data. | ✅ |
| As a user, I want to submit my identity documents so I can become a verified user. | Identity verification (KYC) | Submits a national identity document that an administrator reviews and approves through the web panel before the account can list, apply, or message freely. | ✅ |
| As an adopter, I want to complete a lifestyle profile so I can receive animal suggestions that fit my lifestyle. | Lifestyle profile and matching | Completes a short profile covering home size, activity level, and existing pets, and receives animal suggestions from a rule-based matching engine built on that profile. | ✅ |
| As an adopter, I want to browse and search adoption listings so I can find an animal to adopt. | Browse and search adoption listings | Searches and filters listed animals by species, location, and urgency, independent of any suggestion the matching engine has already made. | ✅ |
| As an owner, I want to post my own animal for rehoming so I can find them a new home. | Adoption listing (owner) | An existing owner posts their own animal for rehoming with photos and a description, using the same listing flow an administrator can moderate. | ✅ |
| As an adopter, I want to submit and track an adoption application so I can adopt a listed animal. | Submit and track an adoption application | Applies to adopt a listed animal and follows the application through pending, accepted, or declined status from the same screen. | ❌ |
| As a user, I want to photograph an injured or stray animal and report it so responders can help. | Rescue reporting | Photographs an injured or stray animal encountered in the field while the app captures the device’s GPS location automatically, and submits the report for triage. | ✅ |
| As a user, I want to message others privately in the app so I can communicate without sharing my phone number. | Private in-app messaging | Communicates with a foster, owner, or administrator through encrypted in-app chat built on SignalR, without exchanging a phone number. | ✅ |
| As a user, I want to earn reputation and trust badges so others can trust my history on the platform. | Reputation and trust badges | Accumulates reputation points and visible trust badges from confirmed activity such as a completed adoption or a verified rescue report. | ✅ |
| As a user, I want to receive push notifications so I know about new messages and status changes. | Notifications | Receives push alerts, through Firebase Cloud Messaging, for new messages, application status changes, and nearby rescue cases that need a verified responder. | ❌ |
| As an adopter, I want to submit an "Apply to Rescue" application on a Rescue post so I can offer to adopt the animal in need. | Apply to rescue | Submits an application to adopt a rescued animal directly from a rescue post. | ✅ |
| As an adopter, I want to see all my approved rescue cases in "My Rescues" so I can track each animal I have committed to. | My rescues tracking | Views a list of all approved rescue applications in the profile section. | ❌ |
| As an adopter, I want to confirm that a transporter has delivered the animal to me so the transport task is marked complete. | Delivery confirmation | Confirms receipt of an animal from a transporter to close the transport task. | ❌ |
| As an adopter, I want to post a Highlight to share a happy moment with my adopted pet so the community can celebrate with me. | Highlight posts | Shares photos and stories of an adopted pet with the community. | ✅ |
| As an adopter, I want to post a Find Home listing for a pet I own so I can find it a new home. | Rehoming listing | Posts a Find Home listing for an owned pet directly to the community feed. | ✅ |
| As an adopter, I want to post a Treatment request when my pet needs vet care so I can communicate the need to the community. | Vet care requests | Posts a treatment request to seek veterinary care support. | ✅ |
| As an adopter, I want to post a Sponsorship request when I cannot cover an animal's care costs so I can seek community support. | Sponsorship requests | Posts a funding request with proof documents to seek financial support for an animal. | ✅ |
