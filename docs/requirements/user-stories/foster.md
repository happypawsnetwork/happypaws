# Foster functionalities

| User story | Functionality | Description | Completed |
| --- | --- | --- | --- |
| As a foster, I want to log in to my foster-facing screens so I can manage cases and messaging. | Login and authentication | Signs in securely with role-scoped, JWT-enforced access to foster-facing case and messaging screens. | ✅ |
| As a foster, I want to submit my identity document for review so I can accept placements and receive alerts. | Identity verification (KYC) | Submits an identity document for administrator review before the account can accept a placement or receive geo-targeted alerts. | ✅ |
| As a foster, I want to receive geo-targeted rescue alerts so I can help when a nearby animal needs a temporary foster placement. | Geo-targeted rescue alerts | Receives a push notification, through Firebase Cloud Messaging, when a nearby triaged case needs a temporary foster placement. | ❌ |
| As a foster, I want to photograph and report injured or stray animals so they can be triaged. | Rescue reporting | Photographs of an injured or stray animal found while out, with the device recording the location automatically for triage. | ✅ |
| As a foster, I want to accept a referred rescue case so I can update the animal's condition and foster status. | Foster placement acceptance and case handling | Accepts a rescue case referred to them, views the case on the live map and case screen, and updates the animal’s condition and foster status as it changes. | ❌ |
| As a foster, I want to transition a fostered animal to an adoption listing so they can be rehomed. | Transition to adoption listing | Once a fostered animal is ready to be rehomed, creates or hands off an adoption listing so the adoption hub can match it with an adopter. | ❌ |
| As a foster, I want to use private in-app messaging to coordinate handover timing so I do not have to share my phone number. | Private in-app messaging | Coordinates handover timing and animal condition with transporters, veterinarians, and prospective adopters through encrypted in-app chat, without sharing a phone number. | ❌ |
| As a foster, I want to earn reputation and trust badges from my foster placements so adopters and administrators can trust me. | Reputation and trust badges | Builds reputation and a visible trust badge from completed foster placements and verified rescue reports. | ❌ |
| As a foster, I want to receive notifications for new nearby cases and messages so I do not miss important updates. | Notifications | Receives alerts for new nearby cases, incoming messages, and status changes on an animal currently in their care. | ❌ |
| As a foster, I want to submit an "Apply to Rescue" application so I can offer to foster an animal in distress. | Apply to rescue | Submits an application to foster a rescued animal directly from a rescue post. | ✅ |
| As a foster, I want to post Update posts linked to my active rescue case so the community stays informed about the animal's progress. | Case updates | Posts progress updates that link back to the original rescue post. | ✅ |
| As a foster, I want to post a Transport request linked to my rescue case so I can find a transporter to move the animal. | Transport requests | Requests a transporter to move an animal linked to an active rescue case. | ✅ |
| As a foster, I want to mark an animal as self-collected when I have my own vehicle so the system records the collection without needing a transporter. | Self-collection | Marks a transport task as completed through self-collection. | ❌ |
| As a foster, I want to confirm that a transporter has delivered the animal so the transport task is marked complete. | Delivery confirmation | Confirms receipt of an animal from a transporter to close the transport task. | ❌ |
| As a foster, I want to close a rescue case once transport is complete so the case is marked as resolved. | Case resolution | Closes an active rescue case after all related transport is completed. | ❌ |
| As a foster, I want to post a Treatment request for an animal in my care so I can seek vet visit support. | Vet care requests | Posts a treatment request to seek veterinary care support. | ✅ |
| As a foster, I want to post a Sponsorship request when care costs exceed my means so I can seek community funding. | Sponsorship requests | Posts a funding request with proof documents to seek financial support for an animal. | ✅ |
| As a foster, I want to see all my active rescue cases in "My Rescues" so I can manage them from one place. | My rescues tracking | Views a list of all active rescue cases in the profile section. | ✅ |
