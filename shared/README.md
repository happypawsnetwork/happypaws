# Shared resources

This directory stores definitions shared across multiple applications in the monorepo.

## API specifications (`api-specs/`)

This directory houses OpenAPI documentation exported from `HappyPaws.Api`. Web and mobile clients, as well as AI coding agents, use these specifications to reference endpoint schemas and generate typed API clients without needing a live backend instance.

## Shared models (`models/`)

This directory houses cross-app data models, validation schemas, and enumerations shared between client applications.
