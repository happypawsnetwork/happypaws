# Happy Paws - Feature Catalog

Interactive feature catalog and user story matrix for the Happy Paws platform.

## Overview

This application documents and demonstrates the end-to-end features, user stories, API endpoints, and platform support across the Happy Paws system for all user roles.

## Tech stack

- React 19
- React Router 8
- Tailwind CSS 4
- Framer Motion
- Lucide React
- Vite 8

## Development

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Build the production bundle:

```bash
npm run build
```
